Arduino Experiment No. 1

LED Blinking

Aim Components Connections Working Procedure Code Output

Aim

To blink an LED using an Arduino digital output pin by turning the LED ON and OFF at a fixed time interval.

About the Experiment

LED Blinking is one of the basic Arduino experiments. It demonstrates how a digital output pin can be controlled using a simple Arduino program.

In this experiment, the LED connected to digital pin 13 is turned ON for 500 milliseconds and then turned OFF for 500 milliseconds. This process repeats continuously.

Procedure

  1. Connect the Arduino UNO to the computer using the USB cable.
  2. Make the LED connections as shown in the Hardware Connections section.
  3. Open Arduino IDE.
  4. Go to Tools → Board and select Arduino UNO.
  5. Go to Tools → Port and select the correct COM port.
  6. Enter the LED blinking program.
  7. Click Verify to compile the program.
  8. Click Upload to upload it to the Arduino.
  9. Observe the LED.

Arduino Code

LED_Blink.ino 
void setup() {
    pinMode(13, OUTPUT); // Set pin 13 as output
}

void loop() {
    digitalWrite(13, HIGH); // Turn LED ON
    delay(500); // Wait for 500 milliseconds
    digitalWrite(13, LOW); // Turn LED OFF
    delay(500); // Wait for 500 milliseconds
}

Result

The LED blinking experiment was successfully implemented using Arduino digital pin 13. The LED continuously switches ON and OFF with a delay of 500 milliseconds.
